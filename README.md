# 2048 — Enhanced Edition

Controls (In-Game)
Key      Action 
← ↑ ↓ →  Move tiles 
U        Undo last move 
R        Restart 
S        Save game 
P        Pause / Resume 
T        Toggle Dark/Light theme 
M        Toggle Sound on/off 
3–6      Change board size 
ESC      Return to main menu 

How to Run
execute main.py
